# Правозащитник — лендинг юридической компании

Адаптивный лендинг для юридической компании «Правозащитник», свёрстанный с упором на чистую семантику, методологию БЭМ и модульную архитектуру SCSS.

---

## Почему давно не было новых репозиториев

На протяжении последних **3–4 месяцев** я не выкладывал новые проекты, так как сфокусировался на глубоком изучении JavaScript и углублении навыков вёрстки:

- Проходил объёмный курс **[The Complete JavaScript Course: From Zero to Expert!](https://www.udemy.com/course/the-complete-javascript-course/)** от **Jonas Schmedtmann** на Udemy (работа JS под капотом, замыкания, DOM, ES6+, ООП, асинхронный JS).
- Вступил в школу **«Кодмастерс Фронтенд»** для дальнейшего системного роста во фронтенд-разработке.
- Учебные проекты из курса я сознательно **не загружал на GitHub**: на мой взгляд, они слишком простые, и выкладывать код, по сути переписанный за автором, не имеет смысла. Вместо количества репозиториев я сделал упор на понимание самой базы.
- Параллельно прокачал и систематизировал работу с **SCSS** — этот проект стал моей практической работой для закрепления модульной архитектуры стилей, адаптива и чистой вёрстки.

## Стек и особенности реализации

- **HTML5:** семантическая разметка (`header`, `main`, `section`, `article`, `nav`, `address`, `figure`/`figcaption`, `time`, `footer`), базовая доступность (`aria-label`, корректные `alt` и типы кнопок).
- **SCSS (`@use`):** модульная структура стилей (`_reset.scss`, `_variables.scss`, `_mixins.scss`, `_functions.scss`, `_layout.scss`, `style.scss`).
- **Функции и миксины:** функция `calcRem()` для автоматического перевода `px` в `rem`, миксины для адаптивных брейкпоинтов (`laptop`, `tablet`, `mobile`, `mobile-sm`).
- **БЭМ:** единый стиль именования блоков, элементов и модификаторов.
- **CSS Grid & Flexbox:** адаптивные сетки, горизонтальный скролл карточек на узких экранах, 3D-переворот карточек специалистов (`transform-style: preserve-3d`, `backface-visibility: hidden`).
